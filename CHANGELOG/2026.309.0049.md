## Summary

Adds `pod-crabbox-code`: the code-server lease image for the Crabbox `containerd` provider, one of the `pod-crabbox-<variant>` images tracked by opencharly/opencharly#869 (W5.2). It is the base lease contract (`opencharly/pod-crabbox`, pinned) plus a pinned code-server release reachable only over the lease's SSH session.

- **`charly.yml`** — the image: `base: ghcr.io/opencharly/pod-crabbox:2026.307.1828` (pinned OCI base), `user: root` (the base's `sshd -D` is PID 1) with the login user left at the base's `crabbox`/uid 1000, and `distro: [cachyos, arch]` + `build: [pac]` declared explicitly because an external OCI base does not inherit the CachyOS chain.
- **`candy/code-server/charly.yml`** — the variant layer: code-server `4.144.0` fetched from the pinned upstream GitHub release tarball into `/usr/local/lib/code-server`, the release entry point linked at `/usr/local/bin/code-server`, and `/usr/local/bin/crabbox-start-code` exec'ing it with `--bind-addr 127.0.0.1:8080` so the editor is reachable only through the lease's SSH session. The candy restates `port: [2222]` (the base's SSH contract) because an OCI base does not carry its candy chain's port label across the boundary.
- **Six deterministic `check:` steps** — the binary is executable; `--version` contains `4.144.0`; the wrapper is executable and contains the loopback `--bind-addr`; the inherited lease binaries (`sshd`, `bootstrap.sh`, `ready`) exist; uid 1000 is `crabbox`; `/etc/ssh/sshd_config.d/99-crabbox.conf` names `Port 2222` and `sshd -t` parses it.
- **`.github/workflows/image.yml`** — the thin caller of the org reusable: `pull_request` / `workflow_dispatch` build only (the reusable derives a `ci-<sha>` tag and publishes nothing), and a successful `tag-on-merge` completion publishes the newest `v*` git tag as the image tag.
- **`README.md`, `AGENTS.md`, `CHANGELOG/.gitkeep`, `.gitignore`** — repo overview, repo guidance, the history directory, and generated-file ignores.
