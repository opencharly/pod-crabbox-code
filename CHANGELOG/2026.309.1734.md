# 2026.309.1734 — feat(bed): add the disposable R10 bed for pod-crabbox-code

## Summary

**Head `141b7080ad7e2cb745a9498582bfaa1ca5fd1533` — 2 files, +281/−0.** Adds
`check-pod-crabbox-code-serves`, the `disposable: true` R10 bed for
`opencharly/pod-crabbox-code`, and documents it in `AGENTS.md`.

Before this change the code-server variant was verified only at the build boundary:
the candy's checks prove the pinned release is installed, reports `4.144.0`, that
`crabbox-start-code` carries `--bind-addr 127.0.0.1:8080`, and that the inherited
lease files exist. A build container never starts the editor, so none of them can
prove the variant's actual claim: **code-server is present and serves inside a
running lease.**

The bed is the check system's three-step shape:

1. **ABSENCE** — reset, assert the instruments exist, then prove the editor is NOT
   serving: nothing listens on its loopback port and an HTTP probe gets no answer,
   while the lease still refuses the freshly generated key.
2. **PERFORM** — write the read-only `/crabbox` inputs temp + `mv` (the contract's
   own input protocol), run the image's shared bootstrap, and start
   `crabbox-start-code` through the lease's **own SSH path** as `crabbox`,
   detached from the channel.
3. **PRESENCE** — the installed release ANSWERS over HTTP: `/healthz` returns its
   own status JSON, the workbench route returns `200` `text/html`, the listener is
   loopback-only and belongs to uid 1000, and the process running it is the
   installed release. The lease contract still holds over SSH as `crabbox` on 2222:
   `id -un`, `sudo -n true`, and `/usr/local/libexec/crabbox/ready` exiting 0.

**The containerd lease substrate is NOT claimed.** In the pinned toolchain a
`pod:` deploy's authored `engine:` selector is dropped by the check-bed
`config`/`start` path (`charly config` emits a podman quadlet) and
`charly deploy add --engine` is an unknown flag — opencharly/charly#1109. The
Docker-compatible socket is also not claimed (opencharly/pod-crabbox-nested#1).
What this bed proves is the image's own, engine-independent running contract on a
disposable pod, the same scope as its three sibling beds.
